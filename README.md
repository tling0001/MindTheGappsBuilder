# MindTheGapps Builder

This repository uses **GitHub Actions** to automatically build MindTheGapps for x86_64 architectures.

## Downloads

> [!NOTE]
> This repository only hosts GApps builds for **Android 16 and 17**.

You can download the latest builds for Android 16 and 17 from the [Releases page](https://github.com/tling0001/MindTheGappsBuilder-for-x86_64-builds/releases/latest).

### Older Android Versions
For older Android versions, please use the following links:
- **Android 14 and 15:** [SourceForge (2024-12-25 release)](https://sourceforge.net/projects/wsa-mtg/files/x86_64/20241225/)
- **Android 12.1 and 13:** [SourceForge (2023-09-18 release)](https://sourceforge.net/projects/wsa-mtg/files/x86_64/20230918/)
- **Android 11 and below:** Please use the [OpenGApps Nano build](https://opengapps.org/) (select x86_64 and nano).
